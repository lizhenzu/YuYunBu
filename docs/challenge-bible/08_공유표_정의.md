# 08. 공유 표 정의 (유년부 운영 DB 에서 자동으로 뽑음)

- 뽑은 날: 2026-11-09 · 원본: 유년부 운영 DB (SQL Server 2014). 지시서 07 의 부록이다.
- ChallengeBible 은 **표 이름 · 칸 이름 · 형식 · 키를 이대로** 만들고, 각 표에 `TenantId INT NOT NULL` 한 칸만 더한다 (Identity 스키마 표는 제외 — 07 의 2장 참고).
- `DM2_VerseKey`(옛 절 번호 짝표)와 `PersonMaster_2026`(교적)은 유년부 전용이라 넣지 않았다.
