- 팀 이름 형식: 사용자가 "홍길동네 팀"으로 적은 적이 있으나 "홍길동네 가족팀"을 유지 중. "현재대로 하고 일괄 수정 금지"라고만 답함.
- 옛 보내기 버튼 2곳: (a) 그대로 / (b) 지움 / (c) 긴 버튼으로 맞춤 — 미응답(현재 그대로).
- 말씀 정리 "영상 구간" 점 기준: 시작 또는 종료 시점을 지정해야 입력됨. 장 전체를 읽는 날은 주황으로 보임 — 바꿀지 사용자가 판단.
- 재시상 남은 경로: 시상 전에 팀을 옮겨 점수를 모으는 경우는 자동으로 막지 않음. 사용자 결정은 "시상할 때 사람이 검증".
