## 표기 약속

- `/컨트롤러/액션` 은 사이트 주소다. 예: `/DailyMission4/Index`
- **역할**은 ASP.NET Identity 역할(`SuperAdmin`, `Admin`, `Moderator`, `Basic`)을 말한다.
- **"Basic" 계정**은 로그인 아이디가 `Basic` 인 특정 계정을 말한다. 일반 회원에게 모두 붙는 `Basic` **역할**과 다르다. (01 문서 참고)
- 날짜·시간은 모두 한국 시간(KST)이다. 코드에서는 `DateHelper.GetKoreaNow()` / `GetKoreaToday()` 만 쓴다.
- 이 설명서에는 비밀번호 · DB 접속 문자열 같은 **비밀 값을 적지 않았다.** 필요한 사람은 운영자에게 따로 받는다.

## 이 설명서를 만든 방법

- 소스 전체(컨트롤러 · 서비스 · 데이터 접근 계층 · 화면)를 읽고, 코드 안의 한국어 설명 주석을 함께 정리했다.
- DB는 운영 DB에서 **구조 정보(표 · 열 · 뷰 · 함수)와 설정용 표의 값만** 읽기 전용으로 확인했다. 개인 정보는 읽지 않았다.
- 실제 화면 동작은 확인하지 않은 부분이 있다. 특히 관리자 화면은 코드 기준으로 설명했다.
