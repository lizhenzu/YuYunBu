# 02. 화면과 메뉴

사용자는 거의 모든 기능을 **홈 화면**에서 시작한다. 홈은 카드(배너)를 세로로 쌓은 한 페이지이고, 왼쪽 위 **☰ 햄버거 메뉴**와 오른쪽 위 **사진(정보 관리)** 이 나머지 기능으로 가는 입구다.

## 1. 첫 진입 — 대기 화면

- 처음 `/` 에 들어오면 서버가 가벼운 **대기 화면**(`Views/Home/IndexSplash.cshtml`, "잠실새내교회 유년부로 가요 · 잠시만 기다려 주세요")을 먼저 보낸다.
- 대기 화면이 곧바로 진짜 홈 `/?_full=1` 을 불러온다. 홈을 만드는 데 1초 넘게 걸려도 흰 화면 대신 카드가 보이게 하려는 것이다.
- 진짜 홈이 뜨면 주소창의 `_full=1` 은 스크립트로 지운다.

- 홈 공용 값은 짧게 메모리 캐시한다(04 문서 "캐시" 참고).
