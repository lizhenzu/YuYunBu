## 8. 알아 둘 기술 사실

- 운영 DB 서버 시계는 한국보다 약 17시간 늦다 (`GETDATE()`). 새 기록의 시각은 `DateHelper.GetKoreaNow()`, 옮긴 옛 기록의 시각은 서버 시간.
- EF `SqlQueryRaw` 는 `smallint` 를 `int` 로 자동 변환하지 않는다 → 꼭 `CAST(... AS INT)`. (이어 읽기 카드가 이것 때문에 조용히 실패했었다.)
- `UserBibleProgress` · `UserBookMark` 는 이제 뷰 + INSTEAD OF 트리거다. EF 는 `AppDbContext` 의 `HasTrigger` 로 알려야 삭제가 된다.
- 운영 서버는 SQL Server 2014 (`STRING_AGG` · `CREATE OR ALTER` 없음).
- PowerShell 5.1 로 한글이 든 스크립트는 UTF-8 **BOM** 으로 저장한다. 커밋 메시지는 파일로(`git commit -F`), Git Bash 명령에는 한글을 넣지 않는다. 옛 git 이라 `switch`/`restore` 대신 `checkout`.
- 이어 읽기는 새 화면 `Bible2` 에만 있다(옛 `Bible` 화면은 그대로).
- 지시서와 형식 설계서는 `docs/challenge-bible/07` · `08` · `09`.
